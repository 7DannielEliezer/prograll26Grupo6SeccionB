## Requisitos Previos
* Docker Desktop / WSL2 activo.

## Cómo Ejecutar la Base de Datos
1. Ejecutar el archivo `start-db.bat` para iniciar el contenedor de SQL Server en el puerto `1483`.
2. Abrir el proyecto en NetBeans y presionar `F6`.
3. Para detener la base de datos al finalizar, ejecutar `stop-db.bat`.
